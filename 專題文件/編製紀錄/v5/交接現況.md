## 四、規則（後續 agent 必須遵守）

### 格式規定（學校要求，不可妥協）
- 字體：中文 **DFKai-SB（標楷體）**、英文/數字 **Times New Roman**。定義在 `work/build/helpers.js` 的 `F = { ascii: TNR, eastAsia: KAI, hAnsi: TNR }`。
- 字級（`helpers.js` 的 `SZ`，半點值）：章 36（18pt）、節 32（16pt）、內文 28（14pt）、表格 24（12pt）。目錄條目一律 14pt。
- 頁碼：封面無頁碼；前置頁羅馬數字（i 起）置中置底；本文阿拉伯數字自 1 起。
- 版面：A4、邊界 1.5cm。設計系統（藍色強調色、藍表頭、斑馬紋表格、章節標題藍條/底線）在 `helpers.js`，改樣式先讀它。

### 目錄是靜態的（重要）
- `main.js` **不可改回** `TableOfContents` 欄位：docx 套件產生的欄位沒有快取內容，LibreOffice 轉 PDF 不更新欄位 → 目錄整頁空白（這就是本次修的 p-02 缺陷）。
- 章節結構有任何增刪後的重建順序：**先** build + 轉 PDF → 跑 `make_tocjson.py` 重萃取頁碼 → **再** build 一次 + 轉檔 → 用新 PDF 重萃取比對 `toc.json` 零差異（閉環驗證）。本文邏輯頁碼不受前置頁數影響，故閉環應恆為零差異。
