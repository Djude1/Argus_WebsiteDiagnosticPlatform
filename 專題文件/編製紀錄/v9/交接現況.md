## 已核對的差異與限制

- 本機 runserver 8000／SQLite／DEBUG eager smoke test、Compose 8081／PostgreSQL／Redis／Worker、公網 K8s／Tunnel／Gateway／GitOps 分開說明。宣告 web、worker、frontend 各兩副本，不等於本輪登入叢集驗證容量或 rollout。
- 公網網域頁正常載入且顯示 Search Console；舊版找不到資源問題本次未重現。沒有重新授權 Google OAuth 或測試新帳號註冊。
- 公網購點為 Stage，未實際刷卡；程式已支援正式模式與定期定額，但沒有跨月實扣驗收。
- 公網健康頁當時 DB、Redis、Worker 可用；近一小時無新完成／失敗任務，掃描執行仍為無法判定，不能當成新掃描成功。
- MCP 畫面生成 HTTP 端點。維運需核對 ARGUS_MCP_PUBLIC_BASE_URL 與代理協定，使公網設定為 HTTPS；本輪未修改公網或建立新憑證。
- 公網 PDF 按鈕可操作，但瀏覽器未取得可核對檔案；下載內容仍未驗證。修正產出畫面為尚未產生，未觸發新模型任務。
- 測試帳密欄位含 encrypted 名稱，但實作為 Django Signer 簽章，文件不將其宣稱加密。Search Console Refresh Token 另為 Fernet 加密。
- Kali 公網設定停用；完整 Docker／PostgreSQL／Redis／Worker 掃描、報告轉檔、Linux 取消、備份還原、負載及修正成效仍待相應環境驗證。
- 組內分工沿用既有資料，規劃項目於表內標示。

## 重建方式

在文件根目錄依序執行 work/v9/prepare_builder.py、work/v9/build_manual.py，再以 work/v9/render_word.py 指定正式 DOCX 與 --output_dir work/v9/render-next --emit_pdf。用 check_document.py render-next --write 回填頁碼後再 build／render；最後不帶 --write 檢查 MAP_CHANGES 0，執行 audit_final.py，真正讀每個受影響頁並交獨立視覺 QA。

排版改在 prepare_builder.py；其會重新產生 build_manual.py。正文來源為四份 chapters_*.md；資料字典依 [ORM 清單](orm_inventory.json) 組出。最終手稿見 [manual_source.md](../../本機資料/work/v9/manual_source.md)。AI使用揭露的頁碼範圍依Word正文及附錄總頁數填寫；分頁改變時同步核對。圖稿存於 diagrams，安全裁切公網截圖存於 ui。raw-captures 與舊渲染只留本機除錯，可能含私人內容，不作交付或分享。
