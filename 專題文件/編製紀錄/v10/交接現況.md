## 重建與驗證

工作目錄為 `<文件工作區>`；執行 shell 為 PowerShell。Python 使用 Codex bundled runtime：`<本機路徑> `<本機路徑> 載入，不安裝全域套件。

必要時才重建；任何 DOCX 修改均需要重新渲染與真正觀看受影響頁面，頁碼變動則重新核對所有目錄。腳本不是部署或應用程式操作授權。

1. 閱讀 [編製契約](artifact.md)、[編輯摘要](editorial_changes.json)、[技術基準](technical_baseline.json) 與 [構建腳本](build_v10.py)，確認來源與允許變動。
2. 使用 bundled Python 執行 build_v10.py 產生 v10；以 [export_and_map.ps1](export_and_map.ps1) 的 InputDocx、OutputPdf、MapJson 參數唯讀開啟 Word，重新分頁、匯 PDF 並收集書籤位置。同時不可啟動多個 Word COM 工作。
3. 再次執行 build_v10.py 回填頁碼，再匯 Word PDF／映射，確認前後目標位置一致；若頁碼變動，重複直到穩定。
4. 以 [render_existing_pdf.py](render_existing_pdf.py) 呼叫 bundled documents/render_docx.py 影像流程，把 Word 實際排版 PDF 轉為全頁 PNG；最終已驗證版本為 final14.pdf 與 render14/page-1.png 至 page-88.png。
5. 執行 [audit_v10.py](audit_v10.py)；主代理及獨立視覺 QA 以 `tools.view_image` 真正讀取最終全頁與必要放大圖，紀錄問題／修復／複驗。不能用 XML 或 OCR 通過取代畫面判讀。
