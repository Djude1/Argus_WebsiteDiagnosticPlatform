# 行動版 RWD 與導覽

## 實作決策

- `SiteNav` 在 920px 以下使用可展開的公開導覽選單，選頁或 Escape 收合；Escape 將焦點還給開啟按鈕。
- 會員工具列在 640px 以下分兩列：品牌與帳號工具在第一列，網站切換器與搜尋／網域驗證／MCP 在第二列。第一列動作跨欄靠右，避免它的寬度壓縮第二列網站名稱。
- `ProjectSidebar` 在 1023px 以下改成「目前分頁／切換分頁」按鈕，展開後提供兩欄功能入口與方案資訊，切換頁面後收合。1024px 起保留桌面側邊欄。
- 行動裝置可安裝 PWA 時，安裝入口移至帳號選單，避免額外按鈕擠壓工具列；桌面仍顯示安裝入口。
- 共用樣式集中在 `frontend/src/styles/74-responsive.css`；會員內容在 `frontend/src/styles/legacy-member/97-responsive.css`，沿用既有範圍處理與深色轉換。不得只在全站樣式改會員內容，否則會被舊版高特異度規則蓋過。
- 手機頁首、卡片及掃描表單採單欄；主要按鈕與工具至少 44px 高。表單文字 16px，長名稱與網址可換行。掃描／頁面表格只在容器內水平捲動；問題清單沿用手機卡片。
- `viewport-fit=cover` 與 `safe-area-inset-*` 為 PWA 的頂部、側邊及底部預留安全邊界。

## 驗證與限制

- 共用主題按鈕的第一次 render 與預先渲染保持夜間狀態，掛載後才依瀏覽器偏好顯示日間圖示；避免日間偏好造成 hydration 不一致與導覽重畫。
- 首頁 `usePrefersReducedMotion` 同樣在掛載後套用裝置偏好，避免「減少動態」使用者接手預先渲染時重畫首頁；後續偏好變更仍會更新。
- Node 22 正式建置與 12 個公開頁預先渲染成功；前端測試、型別檢查通過；lint 0 errors，另有既存後台 hook warning。最終數字見工作記錄。
- 15 個代表頁面在 360、390、768、1024、1440px 共 75 組檢查均無整頁水平溢出。資料由瀏覽器攔截 API 提供虛構樣本，未操作正式資料。
- 獨立視覺 QA 實際讀取 16 張首輪、9 張正式建置補拍及 8 張主題／安裝／動態影格；首次發現舊截圖的切換器名稱過窄，補拍後該問題消失，最後兩輪 0 項可見問題。
- 手機／平板的公開選單、專案選單、切換器、通知、帳號與搜尋已測試。掃描表內容寬 709px／容器 332px，能捲至右端；頁面表內容寬 640px／容器 332px，能捲至右端。
- Android／iOS 實機安裝、實體瀏海安全區、離線與 service worker 更新未在本次驗證；背景掃描、付款與正式部署也不在本次驗證範圍。
