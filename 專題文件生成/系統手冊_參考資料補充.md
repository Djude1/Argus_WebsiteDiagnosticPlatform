### 14-2 開源專案與工具

本系統直接使用的檢測工具、借鑑其檢查規則或設計的開源專案，以及 AI Agent 設計時調研比較的系統：

[9] Auriti Labs。geo-optimizer-skill（GeoReady，MIT 授權）。GEO 可引用性、RAG 分塊、內容衰退、Trust Stack 五層信任分與頁面 AI 提示詞注入偵測的借鑑來源。https://github.com/Auriti-Labs/geo-optimizer-skill
[10] AgriciDaniel。claude-seo（MIT 授權）。UX 假按鈕（div／span 掛 onclick 卻沒有 role）檢查的借鑑來源。https://github.com/AgriciDaniel/claude-seo
[11] ProjectDiscovery。Nuclei。主動模式的模板式弱點掃描引擎。https://github.com/projectdiscovery/nuclei
[12] ProjectDiscovery。nuclei-templates。Nuclei 模板庫；本系統固定版本並只使用 CISA KEV 模板集。https://github.com/projectdiscovery/nuclei-templates
[13] ProjectDiscovery。Katana。全網站主動模式的端點與 JavaScript 資源探索。https://github.com/projectdiscovery/katana
[14] ZAP 專案。Zed Attack Proxy（ZAP）。OWASP ZAP 被動分析（只跑被動規則，不對網站發新請求）。https://github.com/zaproxy/zaproxy
[15] sqlmap 專案。sqlmap。Kali SQL 注入主動驗證工具（正式環境目前停用）。https://github.com/sqlmapproject/sqlmap
[16] RetireJS。Retire.js（規則庫 Apache-2.0 授權）。前端 JavaScript 函式庫版本與已知漏洞比對規則庫。https://github.com/RetireJS/retire.js
[17] Deque Systems。axe-core（MPL-2.0 授權）。WCAG 2.0／2.1／2.2 A／AA 無障礙自動化檢查。https://github.com/dequelabs/axe-core
[18] MDN。HTTP Observatory。安全標頭參考等第的公開評分規則（本系統離線計算，不呼叫該服務）。https://github.com/mdn/mdn-http-observatory
[19] Microsoft。Playwright for Python。爬蟲與 AI Agent 操作的瀏覽器自動化。https://github.com/microsoft/playwright-python
[20] 0xSteph。pentest-ai-agents。Hermes-Agent 專家角色目錄（每個角色附用途與使用時機）的借鑑來源。https://github.com/0xSteph/pentest-ai-agents
[21] Nous Research。hermes-agent。Hermes-Agent 工具能力目錄化（派工選項由角色目錄動態產生）的借鑑來源；名稱相同純屬巧合。https://github.com/NousResearch/hermes-agent
[22] vxcontrol。PentAGI。多 Agent 滲透測試系統；重複工具呼叫偵測、卡住時自動介入與記憶設計的參考。https://github.com/vxcontrol/pentagi
[23] Alias Robotics。CAI（Cybersecurity AI）。Agent 工具整合、廣度優先探索與決策紀錄的參考。https://github.com/aliasrobotics/cai
[24] usestrix。Strix（Apache-2.0 授權）。分階段角色切分與 MCP 式工具命名的參考。https://github.com/usestrix/strix
[25] Keygraph。Shannon（AGPL-3.0 授權）。「沒有實際利用就不列為已確認」證據等級理念的參考。https://github.com/KeygraphHQ/shannon
[26] awarexone。Agentic-Bug-Hunter（MIT 授權）。回報前確認「攻擊者現在就能做到嗎」的檢查精神的參考。https://github.com/awarexone/Agentic-Bug-Hunter
[27] elementalsouls。Claude-BugHunter。依漏洞類別整理攻擊知識的參考。https://github.com/elementalsouls/Claude-BugHunter
[28] GreyDGL。PentestGPT。LLM 滲透測試任務樹與情境遺失問題的參考。https://github.com/GreyDGL/PentestGPT
[29] 0x4m4。HexStrike AI。以 MCP 掛載資安工具之設計的調研對象。https://github.com/0x4m4/hexstrike-ai
[30] aress31。BurpGPT。以 LLM 分析 HTTP 流量之被動掃描的調研對象。https://github.com/aress31/burpgpt
[31] Milan Radic。pentagi-juice-shop-comparison。PentAGI 與 OWASP ZAP 對 Juice Shop 實測比較資料（碩士論文附錄）。https://github.com/MilanRadic/pentagi-juice-shop-comparison
[32] Daniel Miessler。SecLists。敏感路徑與 payload 字典的調研對象。https://github.com/danielmiessler/SecLists
[33] We5ter。Scanners-Box。開源資安工具選型的參考清單。https://github.com/We5ter/Scanners-Box
