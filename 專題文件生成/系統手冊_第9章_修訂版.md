### 9-1-2 AEO 可回答性評分

AEO 以題目權重乘上判定值後換算為百分制。可回答、資訊不足、衝突與無答案的判定值分別為 1、0.5、0.25 與 0；輸入為經篩選的有效計分題目。

來源：backend/apps/scans/aeo/evaluate.py

```python
def _score(results: list[a.QuestionResult]) -> int:
    total_weight = sum(r.question.weight for r in results) or 1
    earned = sum(r.question.weight * a.VERDICT_VALUE[r.verdict] for r in results)
    return round(100 * earned / total_weight)
```

### 9-1-3 分類分數與整體分數

分類評分處理規則去重、扣分與基準分，再依已評估分類計算整體平均。未評估維度不加入分母，AEO 題目結果已含於基準分時不再重複扣分。

來源：backend/apps/scans/scanners.py

breakdown = score_breakdown(

category_scores = {category: entry["score"] for category, entry in breakdown.items()}
deduped = _dedupe_findings_for_scoring(findings)
overall_score = (
    round(sum(category_scores.values()) / len(category_scores))

### 9-1-5 修正產出的資料來源政策

識別值有語料支持時才保留並標示 verified，否則改為 placeholder。這是保留的後端來源政策，不表示目前前端仍有修正產出分頁，也不代表第三方認證。

來源：backend/apps/scans/fixgen/policy.py

```python
def identity_field(
    facts: CrawledFacts, value: str, label: str
) -> tuple[str, dict]:
    """驗證識別類欄位：語料可支撐 → 原值＋verified；否則 → 佔位符。"""
    value = (value or "").strip()
    if value and normalize_for_match(value) in facts.corpus_norm:
        return value, {"status": "verified", "source_url": find_source_url(facts, value)}
    return PLACEHOLDER.format(label=label), {"status": "placeholder"}
```

### 診斷方法與適用範圍

SEO 的逐頁分析讀取已保存 HTML／DOM，呈現 Title、Description、H1、標題結構、正文、Canonical、Robots、圖片 alt、載入時間與 Open Graph。連結檢查另受數量及時間預算限制；畫面的可索引判斷與 Search Console 的 Google 索引結果分開呈現。

AEO 以 rules-v1 擷取正文、建立問題、檢索站內段落並核對答案。正文不足 100 字或有效計分題目少於三題時列為未充分評估。題庫產生且判定無答案的非聯絡類問題不計分；可回答、資訊不足、衝突與無答案採不同判定值，再依題目權重計算基準分，其他頁面規則再影響分類分數。此指標評估已爬取內容的可回答性，沒有實際向所有 AI 搜尋服務詢問，也不保證內容會被引用。

GEO 檢查 JSON-LD、語意結構、可引用內容、llms.txt 與 AI 爬蟲相關訊號。UX 包含行動版版面量測及可選 Agent 行為測試。Agent UX 於全網站且選 UX 時可執行，不必一律使用主動資安模式；能否送出表單仍由網域控制或主動測試條件決定。

被動資安分析公開回應與已取得內容；主動模式依單頁／全網站執行 Nuclei、Katana、敏感路徑及 Agent 等工具。單頁不以 Katana、字典或 Agent 擴成整站。Kali 有 Docker 與 Kubernetes 整合程式，目前 Repo 的 K8s 設定仍為停用。

▼表9-2-2 工具執行的主要條件

| 單頁 | 選取維度的頁面規則及被動檢查。 | Nuclei 限輸入頁；不執行全站 Katana、敏感字典或 Agent 流程。 |
| --- | --- | --- |

### 評分與結果統計

同分類同 rule_id 只計一次懲罰，info 不扣分、不列入 Top Actions。分數使用指數衰減；AEO 使用可回答性基準分，逐題規則不再重複扣分。整體分數的分母是實際評估分類數，未評估維度不以零分或滿分代入。

原始 Finding 筆數、依規則合併的問題數及受影響頁數各有定義。例如同一規則出現在五頁，可有五筆 Finding、一個合併問題及五個受影響網址。因此歷史表與專案總覽的數字可能不同，閱讀時先核對欄位語意。

### 修正產出與網頁優化

後端保留的修正產出包含 JSON-LD、OG／meta、llms.txt 與有依據的 FAQ Schema；欄位標記為 verified、extracted、rule、partial 或 placeholder。verified 表示通過程式的來源政策，不是外部機關認證。缺少依據時由維護者填寫，不補造營業時間、電話、地址、價格或評價。目前前端修正產出分頁已移除，這裡說明的是保留的後端元件。

網頁快照由保存的 DOM 確定性組裝，選用優化服務才呼叫外部模型。下載強制 attachment，預覽受 sandbox 限制，產物與正式網站分開。測試帳密為 API write-only，不進結果與報告；現有欄位採 Django Signer 簽章表示，不能僅因欄位名含 encrypted 就宣稱具有加密保密性。
