## 2 AEO 可回答性評分

AEO 將題目權重乘上判定值，再換算為百分制。可回答、資訊不足、衝突與無答案的判定值分別為 1、0.5、0.25 與 0。輸入為已篩選的計分題目；部分由題庫產生、判定無答案的非聯絡類問題不計分，篩選後不足三題則列為未充分評估。

來源：`backend/apps/scans/aeo/evaluate.py::_score`。

```python
def _score(results: list[a.QuestionResult]) -> int:
    total_weight = sum(r.question.weight for r in results) or 1
    earned = sum(r.question.weight * a.VERDICT_VALUE[r.verdict] for r in results)
    return round(100 * earned / total_weight)
```

## 5 修正產出的資料來源政策

識別欄位有擷取語料支持時才保留原值並標示 verified，否則改為 placeholder 待填欄位。verified 表示通過程式的來源政策，不代表第三方認證或事實真實性保證。此為保留的後端實作，目前前端修正產出分頁已移除。

來源：`backend/apps/scans/fixgen/policy.py::identity_field`。

```python
def identity_field(
    facts: CrawledFacts, value: str, label: str
) -> tuple[str, dict]:
    """驗證識別類欄位：語料可支撐 → 原值＋verified；否則 → 佔位符。"""
    value = (value or "").strip()
    if value and normalize_for_match(value) in facts.corpus_norm:
        return value, {"status": "verified", "source_url": find_source_url(facts, value)}
    return PLACEHOLDER.format(label=label), {"status": "placeholder"}
```

## 6 MCP 沿用既有掃描入口

MCP 共用網站的掃描驗證、建立與派工入口。ScanJobCreateSerializer 的建立流程沿用原本的預扣服務；派工失敗時由共用入口處理退款，避免另外建立一套 MCP 扣點流程。

來源：`backend/apps/mcp_access/tools.py::create_scan`。

```python
serializer = ScanJobCreateSerializer(
    data=data,
    context={"request": ctx.request, "client_ip": get_client_ip(ctx.request)},
)
if not serializer.is_valid():
    raise ToolError("無法建立掃描：" + _flatten_errors(serializer.errors))
scan = serializer.save()
ctx.scan_job = scan
if not enqueue_created_scan(scan):
    raise ToolError(f"掃描 #{scan.id} 暫時無法啟動，預扣的點數已全額退回，請稍後再試。")
```
