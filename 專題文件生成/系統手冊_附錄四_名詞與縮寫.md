# 附錄四 名詞與縮寫對照

> 由 build 流程接在系統手冊附錄三之後。只收錄手冊正文與附錄實際出現的名詞；說明以本系統的用法為準，改功能時與附錄三一起同步。

本附錄整理手冊中出現的英文縮寫（表 D-1）與本平台的專有用語（表 D-2），說明以本系統中的用法為準。

**表D-1 英文縮寫對照**

| 縮寫 | 全名 | 說明 |
|---|---|---|
| AEO | Answer Engine Optimization | 答案引擎最佳化：讓搜尋引擎與 AI 能從網站內容直接找到並引用答案；本系統以網站能回答多少常見問題評估 |
| API | Application Programming Interface | 程式之間交換資料的介面 |
| CDN | Content Delivery Network | 內容傳遞網路，如 Cloudflare；網站在 CDN 之後時，掃描看到的是邊緣節點而非主機 |
| CLS | Cumulative Layout Shift | 累積版面位移：頁面載入時元素跳動的程度，越低越好 |
| CrUX | Chrome User Experience Report | Google 收集的真實 Chrome 使用者效能資料（過去 28 天） |
| CSP | Content Security Policy | 內容安全政策：限制網頁可載入哪些來源的腳本與資源，降低 XSS 風險 |
| CSRF | Cross-Site Request Forgery | 跨站請求偽造：誘使已登入者在不知情下送出請求的攻擊 |
| CVE | Common Vulnerabilities and Exposures | 公開已知漏洞的統一編號 |
| CWE | Common Weakness Enumeration | 軟體弱點類型的分類編號 |
| DMARC | Domain-based Message Authentication, Reporting and Conformance | 告訴收信方如何處理冒用本網域寄出的郵件 |
| DNS | Domain Name System | 網域名稱解析系統 |
| DNSSEC | DNS Security Extensions | 以數位簽章防止 DNS 回應被竄改 |
| EPSS | Exploit Prediction Scoring System | FIRST 組織估算漏洞未來 30 天被利用的機率；本系統只用於排序，不改嚴重度 |
| GEO | Generative Engine Optimization | 生成式引擎最佳化：讓生成式 AI 更容易理解與引用網站內容 |
| HAR | HTTP Archive | 記錄瀏覽器請求與回應的檔案格式；本系統交給 OWASP ZAP 被動分析，用完即刪 |
| HSTS | HTTP Strict Transport Security | 要求瀏覽器一律以 HTTPS 連線的回應標頭 |
| JSON-LD | JSON for Linked Data | 寫在網頁中的結構化資料，讓搜尋引擎辨識組織、文章、商品等 |
| JWT | JSON Web Token | 本系統登入後的存取憑證格式 |
| KEV | Known Exploited Vulnerabilities | 美國 CISA 公告「已確認被實際利用」的漏洞清單；Nuclei 只使用這組模板 |
| LCP | Largest Contentful Paint | 頁面最大內容出現的時間 |
| LLM | Large Language Model | 大型語言模型 |
| MCP | Model Context Protocol | 讓 AI 助理呼叫外部工具的開放協定；會員可用 MCP 憑證讓 AI 助理建立掃描、讀取結果 |
| OWASP | Open Worldwide Application Security Project | 開放網路應用程式安全計畫；發布 Top 10 風險分類與 ZAP 掃描器 |
| RAG | Retrieval-Augmented Generation | AI 先檢索文件片段再回答；GEO 檢查內容是否容易切成適合檢索的段落 |
| SEO | Search Engine Optimization | 搜尋引擎最佳化 |
| SPF | Sender Policy Framework | 宣告哪些主機可代表本網域寄信 |
| SRI | Subresource Integrity | 以雜湊值確認外部腳本、樣式沒有被竄改 |
| TLS | Transport Layer Security | HTTPS 使用的加密協定 |
| UX | User Experience | 使用者體驗 |
| WAF | Web Application Firewall | 網頁應用程式防火牆 |
| WCAG | Web Content Accessibility Guidelines | W3C 無障礙網頁規範；本系統以 axe-core 檢查 2.0～2.2 的 A／AA 項目 |
| XSS | Cross-Site Scripting | 跨站腳本攻擊 |
| ZAP | Zed Attack Proxy | OWASP 開源網頁安全掃描器；本系統只使用被動規則 |

**表D-2 平台用語**

| 用語 | 說明 |
|---|---|
| 網站專案 | 同一網站（協定＋網域＋連接埠）的掃描歸在同一個專案，用來比較每次掃描的問題變化 |
| 單頁／全網站 | 掃描範圍：單頁只檢查輸入的網址；全網站依連結與 sitemap 爬取，最多到頁數上限 |
| 維度 | SEO、AEO、GEO、UX、資安五類檢查，建立掃描時可複選 |
| 被動模式 | 只讀取公開頁面與回應內容，不送出探測請求 |
| 主動模式 | 會送出探測請求（Nuclei、Katana、敏感檔案探測、資安 Agent）；須勾選授權且網域已驗證 |
| 網域所有權驗證 | 以 Google Search Console 擁有者、DNS TXT、首頁 meta 標籤或驗證檔證明擁有網域，有效 90 天 |
| 點數 | 平台計費單位；費用＝頁數 × 維度數 × 每維點數，建立時預扣，完成後依實際頁數結算退差額 |
| 問題 | 一筆檢查結果，含嚴重度、受影響頁面、證據與修法 |
| 嚴重度 | 嚴重、高、中、低、資訊五級；資訊只提醒、不扣分（附錄三表 C-1） |
| 覆蓋紀錄 | 記錄每項檢查是完成、部分完成、失敗或未執行；工具失敗不會被當成「沒有問題」 |
| 規則版本／評分版本 | 判定規則與計分公式的版本；版本不同的兩次掃描不直接比較分數增減 |
| Hermes-Agent | 本系統的 AI Agent，負責擬真使用者體驗測試與已授權的資安測試 |
| 示範專案 | 新帳號自動建立的唯讀範例專案，資料來自虛構網站的真實掃描 |
