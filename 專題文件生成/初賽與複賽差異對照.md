## 二、逐項細節與講法

### 1. 網站所有權驗證（評審最在意）

**初賽時的答法**：使用條款＋自我宣告（授權勾選），AuthorizationConsent 落地 IP／UA／時間／網域供稽核——但承認沒有技術性驗證。

**複賽的答法**：
- 系統內建三種技術性驗證（與 Google Search Console 同等正規的做法）：
  1. **DNS TXT**：在網域加 `argus-site-verification=<token>` TXT 記錄
  2. **meta tag**：首頁 `<meta name="argus-site-verification" content="<token>">`
  3. **HTML 驗證檔**：`/.well-known/argus-verification.txt` 放 token
- **與掃描權限連動**：只有「已通過驗證的網域」才能開啟主動式資安測試模式；未驗證網域只能跑被動掃描
- **人工審核保留**：admin 後台可人工覆寫核准／拒絕（對應問答時承諾的人工審核機制）
- 驗證有 90 天效期，過期需重新驗證

### 2. 後端／API 漏洞檢測（回答「後端程式 bug 掃得到嗎」）

**一句話論述**：我們不讀後端原始碼（也拿不到），而是三層偵測——
1. **被動指紋層（每次掃描都跑）**：回應標頭／Cookie／SSL 指紋辨識後端服務與版本 → 比對 **NVD CVE 資料庫**（內建 `backend_services.json`，可用 `manage.py refresh_backend_cve_db` 更新）；前端庫走 Retire.js 規則庫
2. **閘門式主動層（需授權）**：Nuclei 漏洞模板驗證、Katana 爬取、敏感檔探測——全部有三重授權閘門與頻率預算
3. **Agent 層（可選）**：Hermes-Agent 工具呼叫（含 SQL injection probe）；Kali（sqlmap/metasploit）已實作但正式環境預設關閉，有 runbook 決定開啟時機
- 所有 finding 自動標注 OWASP A01-A10 與 CWE 編號

### 3. 成本效益與商業模式（回答「成本怎麼算、訂閱在哪」）

- **點數制已上線**：每頁 10 點、預扣→實結→退款（冪等）、月贈 200 點、四個購點方案、綠界 Stage 測試環境金流（3 步驟結帳＋發票／載具）
- **複賽新增訂閱**：月費方案 → 每月自動贈點（冪等結算，冪等鍵＝年月）；方案與一次性點數包並列比較；admin 可開通／取消（全程稽核）
- **成本效益分析（設計文件新章）**：K8s 資源 requests/limits 盤點→基礎設施月成本、每掃描成本估算（頁數×RPS×時間）、點數損益平衡、訂閱定價建議、BMC 九宮格

### 4. 防火牆與干擾（回答「會不會被雲端 WAF 擋掉」）

- **降低觸發**：被動 5 RPS／主動 2 RPS 節流、遵守 robots.txt、單次掃描上限 50 頁／深度 3
- **如實呈現**：新增 WAF 偵測——被 403/429 或 challenge 頁超過閾值時，報告產生「掃描遭防護機制部分阻擋」finding，附統計（幾頁被擋、佔比）與建議（降頻、白名單、離峰重掃），並提醒結果可能不完整
- **不越界**：localhost／私有 IP／metadata IP 全封鎖（防 SSRF），DNS 全記錄檢查

### 5. 文件與後台（回答「文件寫齊全、管理員在哪、登入記錄在哪」）

- **管理後台（既有，初賽文件漏寫）**：12 頁——總覽、使用者清單／詳情、交易、評論管理、掃描清單／詳情、訂單、方案、內容 CMS、公告、設定、稽核日誌（superuser）；三層權限（使用者／admin／superuser）；AdminAuditLog 不可刪除
- **登入記錄（複賽新增）**：LoginEvent model 記錄每次登入（方法／IP／UA／時間），admin 使用者詳情頁可看時間軸
- **UML 補齊**：每個功能活動圖＋關鍵流程循序圖（PlantUML）、完整 ER 圖、K8s 部署架構圖（Argo CD／cloudflared／GitOps）
- **語意修正**：CoinWallet「一對一對應 user 禁止直接點 save」→ 白話改寫為「所有點數加減一律經中央點數服務的原子交易程式，防止並發算錯帳」

## 四、複賽 demo 建議流程（10 分鐘）

1. **登入**（30s）：Google 登入 → 提及 LoginEvent 已記錄（admin 頁可看）
2. **網域驗證**（2min）：新增網域 → 展示三種驗證方法頁籤與 token → 用預先設定好的網域按驗證 → 成功徽章——「這就是評審問的所有權驗證機制」
3. **提交主動掃描**（1min）：已驗證網域 → 開主動模式（強調：沒驗證的網域這裡會被系統擋下）→ 說明扣點預估
4. **等待時講後端檢測論述**（2min）：三層偵測（指紋 CVE／閘門主動／Agent）＋OWASP 標注——回答初賽「後端掃不到」的質問
5. **報告**（3min）：四維分數、資安 findings、CVE 證據、修正產出專區、報告防偽查驗頁 /verify、（若觸發）WAF 阻擋 finding
6. **訂閱與成本**（1min）：BillingPage 訂閱方案 vs 點數包、成本效益分析章節
7. **admin 後台**（30s）：12 頁巡禮＋稽核日誌＋登入記錄——回答「管理員在哪」
