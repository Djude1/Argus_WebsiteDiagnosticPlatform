# 下載 PDF 按鈕回饋、示範專案搜尋關鍵字資料、Lighthouse 說明縮短

**日期**：2026-10-11  
**操作者**：Claude

## 變更內容
- **下載 PDF 報告按鈕**（掃描報告頁右上）：
  - 改為主色按鈕，有 hover 光暈、按下縮放、鍵盤焦點框。
  - 按下後顯示轉圈與「匯出中…」並停用，避免重複點擊；失敗時顯示原因。
  - 顏色走自訂屬性 `--dl-*`：建置外掛會把舊版樣式的顏色自動轉暗，按鈕會看不出能按。按鈕也不再套 `secondary-button`，因為它的深色規則特異度較高，會蓋掉主色。
- **示範專案（晨光咖啡烘焙所）的搜尋關鍵字**：
  - 後端 `demo/gsc.py` 產生固定的虛構 Search Console 資料。共 20 個咖啡相關搜尋詞，對應示範網站的頁面；7、28、90 天都有資料，包含每日趨勢與前一期比較。數字由搜尋詞與日期算出，每次相同。
  - 狀態端點回「已連接」並帶 `demo`。網址檢查一律回已收錄；連接、更換、中斷都回 400。
  - 前端標題旁顯示「示範資料」徽章，並隱藏更換資源與中斷連線。
  - 新增預設目標關鍵字（耶加雪菲、手沖咖啡、濾掛咖啡、冷萃咖啡、咖啡豆 訂閱）：新示範專案建立時寫入，migration 0034 補到既有的示範專案（只補空的）。
  - 報告的搜尋詞段落也用同一份示範資料。
- **Lighthouse 說明縮短**：網頁與報告改為一句「只看首頁的基本項目；Argus 分數檢查全部 N 頁，兩者不同是正常的。」
- **版本**：`RENDERER_VERSION` 27 → 28。

## 原因
- 使用者回饋：上一版的說明太長。
- 下載按鈕沒有點擊感，按下後也沒有任何回饋。
- 示範專案的搜尋關鍵字頁只有一句「無法連接」。

## 影響範圍
- 新增 migration 0034（只寫資料，不改結構，可重複執行）。
- 示範資料只出現在 `is_demo` 專案，一般專案不受影響。
