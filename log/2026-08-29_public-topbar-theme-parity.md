# 公開 Top bar 主題對稱與共用化

**日期**：2026-08-29
**操作者**：Codex

## 變更內容

- 將公開導覽、品牌入口、主題切換與登入 CTA 從 `PublicPages.jsx` 抽成 `PublicTopBar.jsx` 共用元件。
- 移除日間主題對 Top bar 寬高、間距、字級、換行與 RWD 的獨立覆寫，讓日夜模式共用夜間既有幾何規則。
- 夜間桌面排版、字級與深色配色維持原樣；日間保留既有淺色背景、文字、按鈕與狀態色，窄視窗 RWD 則改由兩種主題共用單列規則。
- 將 920px 以下 Top bar 由上下兩列改為單列；780px 以下改用浮動手機選單完整呈現六個導覽入口，兩側主要操作固定顯示。

## 原因

公開頁的日間與夜間 Top bar 尺寸不一致，切換主題時 Logo、導覽連結與按鈕會位移；使用者希望所有公開頁共用單一元件，並以夜間 Top bar 的排版、字級與尺寸為準，同時保留日夜各自配色。

## 影響範圍

- 影響六個公開頁的 Top bar：專案介紹、快速檢查、團隊、購買、下載與評論。
- 不修改各頁內容版型、後台導覽或登入後導覽。
- 本次功能變更與驗證紀錄納入同一筆 commit。

## 驗證方式

- `frontend/build-node22.ps1`：Vite production build 通過，共轉換 2042 個模組。
- `uv run --no-sync python backend/manage.py check`：通過，0 個問題。
- 隔離 SQLite 套用完整 migration，六個公開路由皆回應 HTTP 200。
- 瀏覽器逐頁切換日夜模式：320–1280px 的 Top bar 高度差異皆為 0；桌面維持原本單列導覽，780px 以下改用不增加 Top bar 高度的浮動選單。
- 六個公開頁在 472px 日／夜模式皆可展開完整六項導覽，Escape 與選頁後可正確收合；各尺寸皆無水平溢出，console error 為 0。
