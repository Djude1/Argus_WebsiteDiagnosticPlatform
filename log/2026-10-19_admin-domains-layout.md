# 後台網域驗證頁審閱：表格欄位與依狀態給動作（2026-10-19）

## 問題
`/admin/domains` 8 欄 compact 表格（網域｜使用者｜狀態｜驗證方法｜到期日｜人工核准｜最後錯誤｜審核），
每一列都是完整的「備註＋人工核准＋否決」，不分狀態：已驗證生效中的還有「人工核准」、已否決的還有「否決」；
人工核准（by 誰／備註）與最後錯誤各佔一欄，表格要橫向捲動。標題「網域管理」與側欄「網域驗證」不一致。

## 變更（`features/admin/AdminDomainsPage.tsx`）
- 8 欄 → 5 欄：網域（＋使用者）｜狀態（＋生效中、人工核准：誰 · 備註）｜驗證方法（＋上次未通過原因）｜到期日｜審核。
- 審核按鈕依狀態：生效中只有「否決」、已否決只有「人工核准」、其餘兩者皆有；備註輸入保留（原地更新不換元素）。
- 標題「網域驗證」。`62-admin-user-detail.css` 的 `.admin-domain-error` 放寬到 260px。

## 驗證
`npm run lint`、`npm run typecheck`、`npx vitest run`（既有 7 個網域頁測試：篩選網址、核准確認與原地更新、否決危險樣式）。
