# 評論頁全螢幕 RWD 修正

**日期**：2026-07-22
**操作者**：Codex

## 變更內容

- 限制評論 hero 標題在桌面版的最大流體字級
- 保留既有單行標題與評分卡雙欄結構
- 將 1440px、1920px、2560px，以及 0 則評論狀態加入評論頁驗證基準

## 原因

公網在 1920px 全螢幕時，標題會因 viewport 字級持續放大而侵入固定寬度的評分卡，文字被卡片與頁面裁切

## 影響範圍

- 僅影響 `/reviews` 夜間版桌面 hero 標題字級
- 評論 API、評分卡、列表、手機排版與其他公開頁不變

## 驗證方式

- 使用 `frontend/build-node22.ps1` 執行 production build
- 瀏覽器檢查 2560px、1920px、1440px、1280px、768px、390px 與 320px
- 桌機各尺寸的標題與評分卡實際文字間距皆為正值；平板與手機正確改為上下堆疊
- 各尺寸皆無水平溢位，評分卡未超出 viewport，console 0 個錯誤
- `uv run python backend/manage.py check`：0 個問題
