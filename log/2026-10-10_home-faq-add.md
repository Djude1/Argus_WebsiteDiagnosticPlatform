# 首頁常見問題新增 4 題

**日期**：2026-10-10  
**操作者**：Claude

## 變更內容
`frontend/src/features/public/PublicPages.jsx` 的 `HOME_FAQ` 並列新增 4 題（結構與樣式不動，只加資料）：

1. 為什麼 JavaScript 動態載入的內容不會被檢測？（使用者提供的原文）
2. 掃描會不會影響或拖慢我的網站？（被動模式唯讀、速率限制；主動測試受授權控制）
3. 分數是怎麼算出來的？是業界標準嗎？（Argus 自訂模型、指數衰減、可逐項核對、非業界標準）
4. 為什麼有些項目顯示「未評估」？（覆蓋契約：沒跑完／被阻擋／內容太少時標未評估、不假裝沒問題）

## 原因
使用者要在首頁常見問題區塊補充使用者會想知道的網站健檢疑惑，首題文案由使用者指定。後 3 題依 Argus 的真實行為（被動掃描、評分模型、覆蓋契約）撰寫，不誇大。

## 影響範圍
- 僅首頁（`/project`）FAQ 多 4 個可展開項；無功能、API 或樣式變更。
- 屬說明既有行為的 help copy，非對外可見功能異動，未動競賽需求書。

## 驗證方式
- `npm run lint`（0 error）、`npm run typecheck`（通過）、`npx vitest run src/features/public`（5 項通過）。
