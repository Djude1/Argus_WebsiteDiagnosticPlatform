# 恢復 Google 驗證檔並維持驗證狀態

**日期**：2026-10-03

## 變更內容

- 恢復網站管理者提供的 Google HTML 驗證檔，原始內容與指定檔名均保留。
- 在前端模組規則註明網站所有權驗證資產須持續保留，不能因驗證或任務完成而清除。

## 原因

先前發佈已確認正確回應，但後續提交 `934ab54` 以驗證完成為由刪除檔案。新前端因此將該網址回應為 SPA 首頁，Google 再驗證時判定內容錯誤。Google 官方要求完成驗證後仍保留檔案。

## 影響範圍

僅恢復靜態檔及補充保留規則，保留其他已合併功能與介面變更。沒有修改 GSC OAuth、密碼、資料庫或叢集 Secret。

## 驗證方式

- 公網問題已重現：一般瀏覽器、Google 驗證 UA、no-cache 與查詢字串都取得首頁內容。
- public 與 dist 中的檔案均與原始下載檔逐位元組相同，長度為 53 bytes。
- Node 22 build、TypeScript 型別檢查、187 項前端測試與 repository text 檢查通過；lint 無錯誤，保留既有 AdminPages hook 警告。
- 發布後須追蹤 image、GitOps 回寫與公網回應；不能只以 HTTP 200 判定成功，必須比對實際內容。
