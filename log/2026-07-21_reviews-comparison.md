# 評論區獨立比較版

**日期**：2026-07-21
**操作者**：Codex

## 變更內容

- 保留 `/reviews` 原版，新增獨立 `/reviews-next` 比較頁並沿用既有評論 API 與登入狀態。
- 將評論列表改為單欄社群討論流；作者、星等、日期、內文、官方回覆與互動列維持同一閱讀脈絡。
- 新增固定可見的「寫下你的評論」入口；登入者已有評論時，改以獨立「我的評論」區塊顯示並提供編輯／刪除，不在公開列表重複出現。
- 排序改為社群常用的「熱門／最新」；helpful 改成按讚圖示與數字，不再顯示解說文字。
- 使用者評論與官方回覆各自提供按讚與檢舉，不再用整串對話共用的操作列；兩組操作都緊貼內容且不使用水平分隔線。
- 逐則互動維持社群常見的按讚在左、檢舉在右，並以整列空間隔開兩項操作。
- 將官方回覆整個色塊移出使用者正文的縮排欄，左緣與評論卡內容邊界對齊；回覆的讚跟隨官方正文欄，桌面版與使用者內容共用左右基準線，避免讚落在品牌圖示下方。
- 將評分數值與星星在評分欄置中；1080px 以下的堆疊版評分卡以最大 800px 寬度水平置中。
- 新版以既有品牌圖裁切出眼睛圖形，不加正方形外框；官方訊息統一標示為「Argus 官方回覆」。
- 統一 `BrandEye` 小尺寸裁切比例：手機版不再把 42×27px 外框縮成 38×25px，避免同一元件在不同斷點裁掉更多左右訊號線。
- 移除資格聲明、功能教學、滿分說明與跳轉按鈕等多餘文字；保留評分、篩選、留言、回覆、互動、檢舉與分頁等必要內容。
- 比較版評論改為單一正文，不再提供或顯示標題；使用者評論與官方回覆超過四行時才出現「顯示更多／收合」，短文維持原樣。
- 依使用者指定先完成夜間版，日間版暫不製作；夜間版改用深海軍藍表面層級、青色訊號光、琥珀星等與紅色檢舉語意。
- 新增網格與光暈環境動態、標題／評分進場、評分條填入、卡片錯峰、官方回覆與按讚回饋動畫，並支援 reduced motion。
- 後端新增官方回覆獨立按讚與檢舉資料；公開互動只允許已驗證且公開的評論，按讚 toggle 使用交易鎖避免併發 500。
- 後台分開統計使用者評論與官方回覆檢舉，父評論治理不再誤結案官方回覆檢舉。
- 專案內安裝 `lucide-react`，統一使用同一套 24px 線性圖示語言。

## 原因

原評論頁的統計與操作區過於稀疏，圖示與文字太小，檢舉缺乏風險層級，官方回覆頭像也未正確使用品牌圖；另有多處像聲明稿的文案，不符合一般網站閱讀情境。

## 影響範圍

- 新增前端 `/reviews-next` 路由、頁面元件與限定在 `review-next-*` 的獨立夜間樣式。
- `/reviews` 原版保留；評論 API、資料模型與後台檢舉統計新增官方回覆的獨立互動支援。
- `package.json` 與 lockfile 新增 `lucide-react` 依賴。

## 驗證方式

- `frontend/build-node22.ps1`：Vite production build 成功，2,039 modules，`ReviewsNextPage` 維持獨立 lazy chunk。
- `uv run python backend/manage.py test apps.reviews apps.admin_api`：65 項全數通過。
- `uv run ruff check backend/apps/reviews backend/apps/admin_api`：通過。
- `uv run python backend/manage.py check`：無問題；`makemigrations --check --dry-run`：無 migration 漂移。
- 獨立安全審查：Critical 0、High 0；發現的 3 個 Medium（舊評論邊界、按讚競態、檢舉治理混用）已修正並補回歸測試。
- 1280px／768px／390px／320px：文件寬度等於 viewport、無水平捲動；主標題維持單行，使用者評論與官方回覆操作各自顯示。
- 逐則按讚／檢舉觸控區至少 48px；兩組操作列的上邊框實測皆為 0px。
- 1280px：官方回覆色塊左緣與評論卡 28px 內容基準線對齊；使用者正文／讚左緣 243.2px、官方正文／讚左緣 242.8px，次像素誤差 0.4px；兩個檢舉右緣同為 1093.6px。
- 390px：使用者讚對齊使用者正文 42.8px，官方讚對齊帶品牌圖示的官方正文 111.4px；兩個檢舉右緣同為 332.4px，且無水平溢出。
- 1280px：評論標題與長文控制項數量皆為 0，三則短評論的 `clientHeight` 與 `scrollHeight` 均為 29px，確認短文不顯示多餘按鈕。
- 320px：一則超過四行的官方回覆自動顯示「顯示更多」；展開後高度由 107px 增至 134px、`aria-expanded=true`，收合後恢復 107px；頁面無水平溢出。
- 320px／1280px：頁首 `BrandEye` 固定為 56×36px 外框／80px 圖片，兩個官方回覆 `BrandEye` 均為 42×27px 外框／60px 圖片；三者水平可視比例皆為 0.7，回覆圖示彼此尺寸與裁切完全一致。
- 900px 堆疊版評分卡相對 hero 的水平中心誤差為 0px；評分數值相對評分欄中心誤差為 0.5px。
- 熱門／最新排序與星等篩選可操作；選擇 4 星後列表由 3 則正確縮成 1 則。
- 動畫樣式實測存在；模擬 `prefers-reduced-motion: reduce` 後動畫時間降為 0.01ms。
- 公開評論相關 API 均回 200；匿名 App 啟動仍會對既有 `/api/auth/refresh/` 發出一次 403，屬全站登入初始化既有行為，未在本次評論版面範圍修改。
- `npm audit --omit=dev`：既有依賴鏈仍有 1 low／3 high；本次新增的 `lucide-react` 未列入弱點，未擅自執行可能改變版本的 `npm audit fix`。
