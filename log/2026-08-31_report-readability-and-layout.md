# 掃描報告品質改善 第三階段：可讀性與排版重寫

**日期**：2026-08-31
**操作者**：Claude
**依據**：[`docs/scan-report-quality-audit-2026-08-30.md`](../docs/scan-report-quality-audit-2026-08-30.md) 第三階段（C1-C5、D1-D5）

## 變更內容

`backend/apps/scans/reports.py` 由線性堆疊重寫為「樣式工具 + 章節產生器」（約 160 → 560 行），維持單檔，公開介面 `build_scan_report` / `get_severity_display` / `mask_pii_evidence` / `_group_findings_for_report` 不變。

### 排版（D1-D5）
- **封面**：ARGUS 大字 + 品牌強調線 + 目標網址 + 整體分數與評級 + 掃描／產生時間。
- **目錄**：五個章節的表格（非 Word field TOC，避免讀者需要手動更新網域）。
- **章節分頁**、**頁首**（ARGUS 網站健檢報告 | 目標網域）、**頁尾**（品牌 + `PAGE` field 頁碼）。
- **14 個表格**取代段落堆疊：分類分數、分數對照、嚴重度統計、掃描範圍、優先改善建議、每筆發現的中繼資料、授權聲明、名詞解釋、技術索引。
- **嚴重度顏色編碼**，並套用白底可讀的品牌色。

### 可讀性（C1-C5）
- `rule_id` / OWASP / CWE 移出正文，收進附錄「5.3 技術索引」；`evidence_source`（`rule_engine`）與 `evidence_type`（`text`）不再顯示。
- 「Deterministic Evidence」→「檢測依據」。
- 每筆發現固定四段：**問題是什麼 / 為什麼要在意 / 怎麼修 / 修好了怎麼確認**，取代舊版依 severity 切換的三種標題。
- 「5.2 名詞解釋」只列這份報告真的出現過的術語（比對 finding 的標題／描述／修補／證據）。
- 分類代碼改為中文全名（`SECURITY` → 「資訊安全」等）。

### 目視檢查後補修的三個文字缺陷
產出樣本報告逐段閱讀時發現（**測試沒抓到，只有把文件印出來看才會發現**）：

1. **info 項目被描述成威脅**：「Nuclei 探針受 WAF 攔截」（代表防護有效）底下寫著「這類問題會被攻擊者利用，可能導致網站被入侵」——與該項意義完全相反。info 改走獨立結構「這代表什麼」。
2. **info 項目仍出現「怎麼修 / 修好了怎麼確認」**：等於叫讀者去修一個沒壞的東西，並在下次掃描確認它「消失」。info 不再輸出這兩段。
3. **資安的驗證建議寫死成標頭檢查**：「用 curl -I 檢查回應標頭」對「頁面外洩個人資料」完全不適用。改為不假設問題型態的說法。

三項各有對應測試鎖定。

### 新增 `backend/apps/scans/tests_report_layout.py`（14 項測試）
表格 / 分頁 / 封面與目錄 / 頁首頁尾與頁碼 field / 顏色編碼 / 內部識別碼不進正文 / rule_id 在技術索引 / 英文術語已翻譯 / 四段結構 / 名詞解釋只列出現過的術語 / 上述三個文字缺陷。

### 測試取值方式更新（非放寬斷言）
`tests_report_content.py` 的 `_text()` 原本只讀 `document.paragraphs`；資訊改放表格後讀不到內容，導致 3 項誤判失敗。已改為一併讀取表格儲存格。另兩處調整：「實際掃描頁數：3」現在是表格的兩個獨立儲存格，拆成兩個斷言；AI 提示詞的標題改為對使用者友善的「想更深入了解？」，斷言改鎖真正的需求（提示詞內容與使用說明）。

### 文件同步
`backend/apps/scans/CLAUDE.md`：新增「報告的讀者是網站主，不是資安工程師」規則表、排版下限、中文字型 `w:eastAsia` 陷阱、品牌色在白底的對比問題。

## 驗證方式

- `uv run ruff check backend` → All checks passed
- `uv run python backend/manage.py test apps` → **Ran 726 tests，OK（skipped=1）**（前次 712，+14 版面測試，無回歸）
- 產出樣本報告並**逐段閱讀全文**（含表格內容），據此發現並修正上述三個文字缺陷。
- **無法做視覺驗證**：本機沒有 LibreOffice / pandoc，`.docx` 無法渲染成 PDF 或圖片。字型、行距、表格寬度、分頁落點等實際視覺效果**未經確認**，需要在 Word 或 Google Docs 中人工開啟檢視。
