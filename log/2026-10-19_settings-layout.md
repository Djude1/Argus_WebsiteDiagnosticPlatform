# 帳號設定頁審閱：區塊順序與空區塊（2026-10-19）

## 審閱結論
`/settings` 的版面（左側 sticky 摘要：頭像／點數錢包／訂閱狀態，右側區塊；1024px 以下堆疊）合理，不動結構。
兩個小問題：
1. 區塊順序「個人資料 → 外觀 → 登入方式 → 刪除帳號」與頁首副標「個人資料、登入安全、外觀與點數」不一致，偏好設定夾在帳號與安全中間。
2. `has_password=false` 的帳號，「登入方式」區塊只有標題沒有內容，說明還寫著可用密碼登入。

## 變更（`features/account/SettingsPage.jsx`）
- 順序改為 個人資料 → 登入方式 → 外觀 → 刪除帳號（帳號與安全在前、偏好在後、危險操作最後）。
- 沒有密碼時顯示「這個帳號目前只用 Google 登入，還沒有設定密碼」＋「設定用戶名與密碼 →」連到 `/account/setup`。

## 驗證
`npm run lint`、`npm run typecheck`、`npx vitest run`。
