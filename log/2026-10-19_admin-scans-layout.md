# 後台掃描任務頁審閱（2026-10-19）

## 審閱結論
列表（搜尋列 → 單一使用者提示 → 可排序表格 → 分頁）結構合理。
詳情頁：返回 → 標題＋終止／重排 → 狀態｜結果摘要 → 各類別分數 → 優先處置建議 → 爬取警告 → 連結列，
主要問題是**失敗的掃描其錯誤訊息排在最後面**（在爬取警告之後），管理員要捲到底才知道為什麼失敗；
另外優先處置建議的嚴重度、維度與各類別分數標籤是英文原值（high／SECURITY），和全站中文介面不一致。

## 變更（`features/admin/AdminScansPages.tsx`）
- 列表標題「掃描」→「掃描任務」（與側欄一致），說明補「點一列看詳情、終止或重排」。
- 詳情：錯誤訊息面板移到回饋訊息之後、狀態面板之前。
- 嚴重度用 `SEVERITY_LABEL`、維度用中文標籤（`priority N` 維持）。

## 驗證
`npm run lint`、`npm run typecheck`、`npx vitest run`（既有 16 個掃描任務頁測試）。
