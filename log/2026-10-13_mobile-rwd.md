# 行動版 RWD 修正

**日期**：2026-10-13

## 變更內容與原因

手機工具列原本會把網站切換器擠成圖示，網站功能藏在橫向分頁列中，部分操作高度不足。本次改為兩列會員工具列、可展開的公開與專案功能選單，修正手機頁首、掃描表單、局部表格捲動及 PWA 安全邊界。

共用樣式新增 `74-responsive.css`，會員內容新增 `legacy-member/97-responsive.css`，依原順序追加匯入；導覽元件增加收合與鍵盤焦點回復，並新增選單與日間偏好 hydration 回歸測試。共用主題按鈕首次接手與預先渲染保持一致，掛載後才呈現瀏覽器偏好，避免導覽重畫。詳見 [實作決策與驗證](../memory/mobile-rwd.md)。

## 影響範圍

- 公開導覽、會員工具列、專案工作區及掃描報告。
- 公開頁主要內容與既有桌面側邊欄沿用既有設計；未新增 API、路由、計費或資料庫變更。
- 遠端更新與本次 RWD 工作分開：先以 fast-forward 更新，再修改前端。原本未提交的本機文件已備份並保留。

## 驗證方式

- `frontend/build-node22.ps1`：正式版與 12 頁預先渲染成功。
- 前端 `npm test`：50 個測試檔、297 項測試通過，含公開／專案選單、兩項主題按鈕及減少動態偏好的 hydration 回歸。
- `npm run typecheck` 通過；`npm run lint` 0 errors、1 個既存 `AdminPages.jsx` hook warning。
- `uv run python backend/manage.py check`：0 issues。
- Playwright／Edge：15 頁 × 5 尺寸無整頁水平溢出；另測選單開關、Escape、表格左右端。API 皆使用虛構資料，未送出掃描、付款或其他正式操作。
- 主代理與獨立 QA 均實際讀圖；補拍確認切換器、表單與局部表格排列正常。
- 日／夜偏好的公開首頁、免費工具、下載與登入頁正式版載入皆無 React hydration 例外。視覺 fixture 關閉 service worker，避免快取與 API 攔截相互干擾；這不代表完成 PWA 離線驗證。
- 首頁輪播以兩組相隔 2.8 秒的影格複驗：一般偏好由步驟 1 切至步驟 2，減少動態時保持步驟 1；三種寬度的正式版導覽互動均通過，無 React 例外。
- 實機 PWA、離線更新與正式部署未驗證。
