# 密碼重置與帳號接管（WSTG-ATHN-09）

tags: reset, forgot password, security question, account takeover, 帳號接管, 密碼重置

## 答案來源推理（核心）
安全問題的答案本質是「關於某人的公開可推事實」。常見題型：第一隻寵物名、
出生地、就讀學校、母親姓氏、最愛顏色/食物。推答案的情報源：
- 目標站的公開內容：個人簡介頁、留言/評論文字（常自帶生活細節）、
  暱稱、註冊 email 前綴
- 站內既有洩漏面：其他使用者的留言提到該用戶、備份檔、商品描述
  （店家自己寫的介紹常含個人色彩線索）
- 回應本身的提示：錯誤訊息可能洩漏答案長度/格式

## 流程四步（全通＝帳號接管）
1. 枚舉：找 security questions 清單端點（GET 常匿名可讀）與 reset 端點
2. 推答案（上法）→ 提交
3. 拿 token/連結 → 設新密碼
4. 以新密碼登入驗證 → 立即 report（最高證據等級）

## 通用缺陷檢查
- token 重放：同一 reset token 用第二次仍成功＝一次性失效缺陷
- token 可預測：觀察多個 token 樣本的長度/字元集/規律（時間戳 base、
  遞增序號）——可預測＝可偽造
- 回應差異枚舉：email 存在/不存在的回應長度或延遲差＝用戶枚舉
- host 鎖定：reset 連結的 host 參數可控＝惡意導向
- 舊密碼欄跳過：只送新密碼欄（不帶 current/old password 欄位）測試
  是否強制驗舊密碼
