# 站內情報交叉比對（OSINT on-site）

tags: osint, cross reference, 站內情報, 交叉比對, metadata

## 情報源盤點（先收集再攻擊）
- 公開使用者內容：留言/評論/評分/問答——常自帶人名、寵物、城市、
  職稱等可推屬性
- 個人頁/公開 profile：自介、網站欄、社群連結
- 商品/內容描述：作者本人寫的——含個人色彩（店主的貓、創辦人背景）
- 回應 metadata：建立時間、作者 email 遮罩（部分遮罩可推全名）、
  使用者 id 關聯
- 檔案下載面：備份/文件檔內的內部資訊

## 交叉比對手法
1. 建目標帳號的屬性清單（從上述源）
2. 對應安全問題/驗證問題類型（寵物名→找站內提到寵物的內容）
3. 對應 email 前綴/暱稱慣例（firstname.lastname@）

## 通用價值
即使不為解鎖特定功能：email 遮罩可逆推、使用者枚舉、內部路徑/版本
洩漏——各自獨立 finding。
